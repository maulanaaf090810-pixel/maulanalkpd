E. AKTIVITAS 3: KONVERSI STRING MENJADI NUMBER

Perbaiki program agar menghasilkan 30. Gunakan Number()[cite: 2]:

Catat hasil program[cite: 2]: 30[cite: 2]

G. TANTANGAN: PROGRAM HITUNG NILAI

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3[cite: 2].

Algoritma saya[cite: 2]:

  1. Meminta input nilai tugas, UTS, dan UAS melalui prompt()[cite: 2].
  2. Mengonversi seluruh input string menjadi angka menggunakan fungsi Number()[cite: 2].
  3. Menghitung total nilai ketiganya lalu membagi 3 menggunakan rumus (tugas + UTS + UAS) / 3[cite: 2].
  4. Menampilkan hasil rata-rata nilai ke console atau layar.
